# 日志分析工具

右键分析日志文件夹，在浏览器窗口里查看离线时间趋势图。首版实现 `charge-log`。项目使用 Python 3.10 或更高版本的标准库和原生浏览器组件，无需安装第三方包。

## 下载项目

在仓库页面点击 **Code → Download ZIP**，解压到固定目录。打开解压后的目录，确认能看到 `main.py`。安装了 Git 也可以用下面的命令下载。[GitHub 仓库](https://github.com/Waikkii/Ultra_log_analysis)

```powershell
git clone https://github.com/Waikkii/Ultra_log_analysis.git
cd Ultra_log_analysis
```

## 在 Windows 安装右键菜单

1. 在包含 `main.py` 的项目目录打开 PowerShell。可以在资源管理器地址栏输入 `powershell` 并按回车。
2. 执行 `py --version`，确认显示 Python 3.10 或更高版本。若只有 `python` 命令可用，执行 `python --version` 检查，并在后续命令中用 `python` 替换 `py`。需要安装 Python 时可从官网下载。[Python 下载](https://www.python.org/downloads/)
3. 执行安装命令。菜单为当前用户安装，无需管理员权限。

```powershell
py main.py install-context-menu
```

安装后，在资源管理器中右键点击包含日志的**文件夹本身**，选择 **解析charge-log**。Windows 11 上从 **显示更多选项** 进入。分析完成后会在默认浏览器中打开图表。**解析hilog** 和 **解析kmsg** 已预留入口，点击时会显示开发状态。

如果移动了项目目录或更换了 Python 安装位置，从新位置重新执行安装命令。要卸载菜单，在项目目录运行下面的命令。

```powershell
py main.py uninstall-context-menu
```

## 从命令行分析

在项目目录运行下面的命令。第一条使用内置样例，第二条演示如何分析自己的日志目录。将示例路径替换成实际路径，路径中有空格时保留引号。macOS 和 Linux 可使用 `python3` 代替 `py`。

```powershell
py main.py analyze charge-log examples/charge-demo
py main.py analyze charge-log "D:\logs\phone capture"
```

报告包含用于绘图的数据和已读取的源日志全文，默认保存在本机临时目录。要把报告保存在指定位置，使用 `--output`。加上 `--no-open` 可仅生成报告，之后双击 HTML 文件即可离线使用。分享报告时，请按源日志的敏感程度处理。

```powershell
py main.py analyze charge-log examples/charge-demo --output demo.html --no-open
```

## 查看图表

1. 在左侧 **数据列** 中搜索并勾选要绘制的列，可同时显示数值列和文字列。
2. 将鼠标移到图上查看采样时刻的值，滚轮缩放时间，拖动平移，点 **全时段** 恢复完整范围。
3. 每条数值曲线默认依据当前时间窗口内的最小值和最大值自动缩放。纵轴较多或窗口较窄时，图中的百分比表示曲线在自身纵轴范围内的位置，图例仍显示实际数值范围。
4. 展开图表下方的 **源文件**，点击文件名即可在其下方查看原文，包括原始空格和制表符。

### 让几列共用纵轴

1. 在 **数据列** 中勾选要比较的曲线。使用样例时可以勾选 `vbat_v` 和 `vsys_v`。
2. 点 **共用纵轴**，输入分组名称，勾选需要共用纵轴的列，再点 **添加分组**。每组至少两列，组内须同为数值或同为文字。
3. 关闭设置窗口查看结果。同组数值列按相同范围绘制，同组文字列的相同状态使用相同的阶梯刻度。可在 **共用纵轴** 中编辑或删除分组，设置在当前页面内生效。

## 常见问题

- **看不到右键菜单。** 确认安装命令提示成功，并右键点击日志文件夹本身。Windows 11 上还需打开 **显示更多选项**。若已经移动项目，重新安装一次右键菜单。
- **分析完成后浏览器没有打开。** 在项目目录运行命令行示例，复制终端打印的 HTML 路径，在资源管理器里打开该文件。
- **图表没有数据，或曲线中间断开。** 确认 `charge-log.0` 等文件直接位于所选文件夹内。若页面出现 **解析提示**，可展开查看具体文件和行号。空字段和 `None` 对应的时间点会留空。

## 日志格式

- 读取目录下文件名匹配 `charge-log.<数字>` 的文件。文件按数字后缀读取，采样按日志中的日期和时间合并。支持轮转文件沿用上一份文件的表头，以及同一批文件内的表头更新。
- 表头以 `Time` 开始，后接用空白分隔的数据列名，列名可变。采样行以 `2026-11-18 15:37:17 >` 这样的时间开头。字段齐全时，按表头列顺序解析，空格数量可以和表头不同。图表保留日志原样记录的时钟时间。
- 数值列支持十六进制、整数、小数和科学计数法。含文字的列使用离散状态。空字段和 `None` 在图上留空。解析时使用制表符分隔或可推断的空格布局定位缺失字段。只有任意数量的空格且无法确定字段归属时，保留采样时间，将该行作为缺失值并在 **解析提示** 中标出位置。

## 扩展分析器

`charge_analyzer/analyzers.py` 维护分析器名称、菜单标签、图表标题和解析函数。新增解析函数后填入注册表即可复用命令行、Windows 右键入口和离线图表。解析结果由 `folder`、`files`、`columns`、`rows` 和 `warnings` 组成。每行包含以毫秒表示的时间 `time` 和按列顺序排列的 `values`。每列包含名称 `name`、类型 `kind`（`number` 或 `category`）和状态列表 `categories`。

可通过 `source_contents` 字段传递从文件名到已解码原文的映射，用于在源文件列表中展开查看。
